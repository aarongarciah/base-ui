## Usage guidelines

- **Form controls must have an accessible name**: It can be created using a `<label>` element or the `Field` component. See the [forms guide](/react/handbook/forms).

## Anatomy

Import the component and use it as a single part:

```jsx title="Anatomy"
import { Input } from '@base-ui/react/input';

<Input />;
```

## Accessibility

- **The automatic wiring described in the subtitle requires wrapping `<Input>` in [`<Field.Root>`](/react/components/field)**: on its own, `<Input>` is a plain native `<input>` and doesn't pick up `aria-labelledby`, `aria-describedby`, or `aria-invalid`. Inside a `Field.Root`, it receives all of these automatically—see [Field's accessibility notes](/react/components/field#accessibility).
- Without `Field`, label it directly with a wrapping or sibling `<label>`, per the [Usage guidelines](#usage-guidelines) above.
